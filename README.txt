HOW TO PUBLISH TO THE EXISTING GITHUB PAGES SITE
Repository: https://github.com/skyrenzaglobal-hash/SkyRenzaglobal
Current website: https://skyrenzaglobal-hash.github.io/SkyRenzaglobal/

1. Download and unzip this package on a computer, or use GitHub's Add file / Upload files feature if working from a phone.
2. In the repository's main branch, upload the files at the root level: index.html, services.html, industries.html, about.html, contact.html, styles.css, pages.css, script.js.
3. Upload the complete assets folder and all files inside it. Keep the exact file names and folder structure.
4. If GitHub asks whether to replace existing files, replace the matching old site files after confirming you are in the correct repository. Keep the old version downloaded as a backup first.
5. Commit the changes to the main branch.
6. Wait for GitHub Pages to publish, then open the website URL above and refresh. On mobile, try a private/incognito tab if an old cached version remains.

CHECK BEFORE COMMITTING
- index.html and all four other HTML files are at repository root (not nested inside the ZIP folder).
- assets/ is at the same level as index.html.
- asset names match exactly, including uppercase/lowercase.
- Do not upload the ZIP file alone; GitHub Pages needs the extracted files.

No website package can alter the live site until these files are uploaded and committed to the repository.
